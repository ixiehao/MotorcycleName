# 参与贡献 / Contributing

感谢你帮助改进「多语言摩托车车名资料库」。欢迎任何形式的贡献——新增车型、修正数据、翻译或文档改进。

Thank you for helping improve the Multilingual Motorcycle Name Database. Contributions of any size are welcome — new models, corrections, translations, or documentation.

## 快速开始 / Quick Start

```bash
# 1. Fork 并克隆仓库 / Fork and clone the repository
git clone <your-fork-url>

# 2. 仅修改 data/ 目录（dist/ 由脚本生成）/ Make your changes in data/ only (dist/ is generated)

# 3. 校验 / Validate
python3 scripts/validate.py

# 4. 构建 / Build
python3 scripts/build.py
```

## 如何贡献数据 / How to Contribute Data

### 新增或修正车型 / Adding or correcting a model

1. 打开 `data/models/` 下对应的文件（命名 `cc_brand.json`，如 `jp_honda.json`）。
2. 新增或编辑车型条目。每个条目**必须**包含：

```json
{
  "id": "model:brand:model-name",
  "brand": "Brand",
  "names": {
    "en": "Model Name",
    "zh-CN": "型号中文名",
    "zh-TW": "型號繁體名",
    "ja": "モデル名"
  },
  "segment": "class:disp:400cc",
  "body_style": "body:naked",
  "powertrain": "pt:ice",
  "status": "current",
  "years": "2000–present",
  "note": "Short description",
  "verified": "verified",
  "source_url": "https://manufacturer.example/model"
}
```

### 必需规则 / Required rules

- **四语言**：`en`、`zh-CN`、`zh-TW`、`ja` 均必填 / **Four languages**: `en`, `zh-CN`, `zh-TW`, `ja` are all required.
- **唯一 ID**：格式 `model:<brand>:<name>`，不得复用已有 ID / **Unique IDs**: format `model:<brand>:<name>`; never reuse an existing ID.
- **引用合法性**：`segment`、`body_style`、`powertrain` 必须引用 `data/motorcycle_classes.json` 中的条目（格式 `class:disp:*`、`body:*`、`pt:*`）/ **Reference IDs**: must reference entries in `data/motorcycle_classes.json` (format `class:disp:*`, `body:*`, `pt:*`).
- **品牌须存在**：`brand` 字段必须与 `data/brands.json` 中的品牌名完全一致 / **Brand must exist**: the `brand` field must match a brand name in `data/brands.json` exactly.
- **勿编辑 `dist/`**：由 `scripts/build.py` 生成 / **Do not edit `dist/`**: it is generated by `scripts/build.py`.
- **状态取值**：仅限 `current`、`discontinued`、`concept` / **Status values**: only `current`, `discontinued`, or `concept`.
- **核验链接**：新近录入或更新的车型应附 `source_url`，优先指向制造商或展会主办方页面 / **Verification link**: newly added or updated models should include a `source_url`, preferably from the manufacturer or organizer.

### 跨市场异名 / Cross-market aliases

同一车型在不同市场的不同名称请添加到 `data/models/cross_market.json`（如川崎 Eliminator 400 与 Eliminator 450、本田 H'ness CB350 与 GB350）。

Same model sold under different names across markets go in `data/models/cross_market.json` (e.g., Kawasaki Eliminator 400 vs. Eliminator 450, Honda H'ness CB350 vs. GB350).

跨市场异名同样是公开数据条目，必须提供 `names.en`、`names.zh-CN`、`names.zh-TW` 和 `names.ja`。`main` 保留为向后兼容的规范主名；`aliases` 则保留各市场实际使用的名称。

Cross-market aliases are public data entries too, so they must include `names.en`, `names.zh-CN`, `names.zh-TW`, and `names.ja`. Keep `main` as the backwards-compatible canonical label, and use `aliases` for the name actually used in each market.

## 核验标记 / Verification Flags

- `verified: "verified"` — 已对照可靠来源确认（官方网站、维基百科）/ confirmed against a reliable source (official site, Wikipedia).
- `verified: "pending"` — 尚未确认；并需在 `data/pending_verification.json` 中添加条目并说明原因 / not yet confirmed; also add an entry to `data/pending_verification.json` with a reason.

## 提交规范 / Commit Guidelines

- 使用清晰、祈使句式的提交信息：`Add Yamaha YZF-R1 (2025)`、`Fix Suzuki GSX-R750 year range` / Use clear, imperative commit messages.
- 每次提交只做一项逻辑变更 / One logical change per commit.
- 提交前必须运行 `validate.py`，且结果为 **0 错误 / 0 errors** / Run `validate.py` before committing; it must finish with **0 errors**.

## 行为准则 / Code of Conduct

请保持尊重与建设性。本项目面向全球贡献者开放；以善意沟通，保持讨论的专业性。

Be respectful and constructive. This project is open to contributors worldwide; assume good faith and keep discussions professional.
